# Tech Get Info

Tech Get Info is a web development project built with HTML, CSS, and JavaScript as part of a school assignment.

> For personal reasons, I have chosen not to include the `images` directory in this repository.

## Features

- Simple and responsive web interface
- Explore page for browsing content
- Member page for displaying member information
- Clean and organized website structure

## Technologies Used

- HTML5
- CSS3
- JavaScript
